Program Dashboard — User Guide

Getting started: Drop your .xlsx file anywhere on this page. The dashboard auto-populates from the data in your file. You can drop a new file at any time to reload.

Tabs

Gantt ChartFull program schedule with WBS, dependency arrows, today line, and work-day tracking. Best for: engineers and PMs. Drag bars to adjust dates; click any task name, team, or % to edit inline.
SpecificationsAll vehicle/system performance specs with status (Achieved / Target / TBD). Best for: engineers. Click any row for dependencies and risk flags.
Program DashboardKPI summary: overall completion, milestones, phase progress, spec status, team workload. Best for: leadership and PMs.
Weight BudgetMass budget bar chart by subsystem. Shown only if your Excel includes a Weight Budget sheet. Best for: engineers.
Org ChartReporting hierarchy. Shown only if your Excel includes an Org Chart sheet. Click any person card for their team tasks. Best for: PMs and leadership.

Required Excel sheets

Sheet names are case-sensitive. Required sheets:

  • Project Info — Field / Value pairs (Project Title, Project Subtitle, Program Start, Program End, Work Days, Phase N Name…)
  • Schedule — Task ID, WBS, Task Name, Category, Start Date, End Date, % Complete, Dependencies, Responsible Team, Milestone (Y/N), Notes
  • Specifications — Spec ID, Category, Specification Name, Value, Units, Status (Achieved/Target/TBD), Responsible Group, Notes, Dependent Task IDs

Optional: Org Chart (Name, Title, Team, Reports To, Email) · Weight Budget (Subsystem, Group, Target Weight (lb), Estimated Weight (lb), Status, Notes)

If something looks wrong

  • A tab is blank → check that the sheet name in your Excel matches exactly (including capitalisation).
  • Gantt bars are missing → check that Start Date and End Date columns contain valid dates, not text.
  • Weight Budget or Org Chart tab is not showing → those tabs only appear when the matching Excel sheet has data.
  • Work days look wrong → use the Work Days button in the Gantt toolbar, or add a Work Days row to Project Info (e.g. Mon,Tue,Wed,Thu,Fri). Default is Mon–Fri.

Saving your edits

Use Export to Excel in the top-right to export your current dashboard back to a dated .xlsx file. The exported file can be re-imported into this tool.
